# 《黎明行者之血》中文任务指南

一个面向玩家的《黎明行者之血》（The Blood of Dawnwalker）中文任务资料站。

**在线阅读：** [https://rainbowcoke.github.io/dawnwalker-quests/](https://rainbowcoke.github.io/dawnwalker-quests/)

## 可以查什么

- 主线、人物任务线、独立任务、宫廷活动和探索集合。
- 任务的中文名、英文名、相关人物、前后关系与不同结果。
- 任务开端的无剧透简介，以及按需展开的完整故事和关键选择。

## 如何使用

在左侧目录按分类浏览，也可以搜索任务名称、英文名称、人物或关键词。任务简介默认不显示结局；需要了解完整流程时，再点击“阅读完整故事（含剧透）”。

手机上选择任务后会进入阅读页，点击“返回目录”即可继续查找，搜索和目录位置会保留。

## 收录说明

当前资料整理自 205 条游戏任务档案，其中 193 条可在网站中阅读，其余记录作为集合背景或归档信息保留。任务名称、触发条件和结果可能随着游戏版本更新而变化。

如果发现遗漏或错误，可以前往 [GitHub 仓库](https://github.com/rainbowcoke/dawnwalker-quests) 查看项目或提交反馈。
