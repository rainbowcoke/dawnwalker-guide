# 《黎明行者之血》中文游戏指南

查任务、比较装备、规划技能点、找制作配方。这个指南为《黎明行者之血》（The Blood of Dawnwalker）玩家整理中文资料，并保留英文名称，方便对照游戏内容。

**[打开在线指南](https://rainbowcoke.github.io/dawnwalker-guide/)** · 浏览器中即可使用，支持电脑和手机。

## 开始使用

1. 打开指南，选择首页卡片或顶部栏目，再进入需要的分类。
2. 已知名称时，点击右上角的搜索按钮，输入中文名、英文名或关键词。全局搜索可以同时查找四个栏目。
3. 进入分类后，用“搜索本页”和筛选条件缩小范围。本页搜索只查当前分类。
4. 点击条目查看详情。装备、技能和消耗品会打开详情卡片；“获取方式”和“手册获取”等内容需要展开查看。

关闭详情卡片后，可以继续浏览原来的位置，筛选条件也会保留。电脑上可按 `Esc` 关闭卡片，也可以用浏览器后退按钮关闭。条目地址可以收藏或分享，之后可直接打开。

## 查任务与控制剧透

任务页先显示“故事开端 · 无剧透简介”。需要查看完整剧情和关键选择时，再展开“阅读完整故事（含剧透）”。全局搜索不检索任务的完整故事和结局正文。

**主线与结局分类、任务名称、任务关系和获取方式仍可能透露剧情线索。** 如果希望尽量少接触剧透，可以先按当前任务名称搜索，只阅读简介，按需展开后续内容。

阅读后可通过“返回所属分类”继续查找，也可以进入所属任务线或探索集合，查看相关任务。

## 比较装备

装备分为武器、上装、下装、护手、靴子、项链和戒指。进入分类后，可结合稀有度、武器类型或护甲类型筛选。

“装备等级”可选 **1—50 级，默认 50 级**。比较装备前，先选好要查看的等级；列表和详情会同步显示该等级的属性。切换装备分类时，会保留所选等级。

价格标注为基础价格。查获取途径时，请展开详情中的“获取方式”；指南仅展示已收录的信息。

## 规划技能点

进入巫术、剑术或血族技能树后，点击节点旁的 `+` 或 `−` 调整技能等级，点击节点查看各级效果、学习时间和条件。页面会显示总投入点数及三类技能的投入点数。

- 无法加点时，查看按钮提示或技能详情，确认前置技能和点数要求。
- 减少前置技能等级后，不再满足条件的后续等级会自动退回，并退还对应点数。
- “撤销”可恢复上一步操作；“清空方案”可重新规划。
- 拖动画布空白处可移动技能树，手机上可用双指缩放。

三个技能分类共用一个加点方案。部分技能效果随角色等级变化，可调整“角色等级”查看。

**加点方案只在当前标签页内保留，刷新或关闭页面后会清空。** 如需留存，请在离开前自行记录。

## 查消耗品与制作配方

消耗品分为“制作”和“非制作”两类。可以按稀有度、制作分类或使用时段筛选；使用时段分为全天、仅限白天、仅限夜间。

打开详情后，可查看物品效果、持续时间和使用条件。可制作物品还会显示材料及数量、基础制作数量和相关条件。部分物品效果随角色等级变化，可在详情中选择等级查看。

## 资料说明与反馈

任务资料整理自 205 条游戏任务档案，部分记录作为集合背景或归档信息保留。指南中的名称、条件、数值和结果可能随游戏版本更新而变化；遇到差异时，请以当前游戏中的显示为准。
